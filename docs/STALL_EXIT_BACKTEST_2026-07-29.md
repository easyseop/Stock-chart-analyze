# 전략 A 절반익절 후 정체청산 백테스트

- 실행일: 2026-07-29
- 기준 커밋: `ba30f9c7` (`claude/happy-gauss-cwoq21`, PR #92 병합본)
- 목적: `+1R 절반익절` 뒤 잔량이 끝없이 남는 문제에 대해
  `10/20`, `15/30`, `20/40` 거래일 규칙을 같은 진입 이벤트로 비교
- 결과 파일: `/private/tmp/stall-exit-backtest.json`

## 비교한 규칙

각 조합의 앞 숫자는 정체 시 추적폭을 `1.5R → 1.0R`로 좁히는 거래일,
뒤 숫자는 잔량을 정체청산하는 거래일이다. 최고가가 직전 정체 기준보다
`+0.25R` 이상 높아지면 정체일을 0으로 되돌리고 1.5R 폭으로 복원한다.
이미 올라간 손절선은 절대 내리지 않는다.

## 표본

개인 KIS 보유종목은 외부 시세 서비스로 전송하지 않았다. Git에 이미 공개된
종목군 15개만 사용했고, 일봉 수집은 15/15 성공했다.

`RDDT, ENPH, HMC, UPST, 006800, AAL, AAOI, AAON, AAPL, ABCL, ABNB, ACAD,
ACGL, ACHC, ACMR`

현행 `now` 진입 게이트를 5거래일 간격으로 워크포워드 재생해 공통 진입
22건을 얻었다. 미래 봉을 보고 손절선을 먼저 올리지 않도록, 당일 저가에는
전일까지 확정된 손절선을 적용한 뒤 당일 최고가·정체 상태를 갱신했다.

타임스탑 6건이었다. 이 표본에서는 30일 정체청산까지 살아남은 거래가 0건이라,
위 결과는 주로 추적폭을 좁히는 시점 차이에서 나왔다. 조합별 차이는 AAPL의
2개 거래에 집중됐다.

## 판정

10/20이 가장 높았지만 22건·15종목의 작은 공개 표본이며 차이가 2개 거래에
집중되어 과최적화 근거로 쓰기 어렵다. 따라서 기본값은 중간안 `15/30`으로
유지하되 `STALL_EXIT_MODE=off`를 기본으로 둔다.

운영 순서는 다음과 같다.

1. 코드 병합 뒤에도 `off` 유지
2. KIS 장부 이관·잔고 검증 완료
3. `shadow`로 1–2주 관찰하며 실제 주문 0건 확인
4. 그림자 제안과 기존 1.5R 결과를 비교해 재검토
5. 별도 승인 때만 `live`

이 결과는 투자 성과 보장이 아니며, `live` 전환 근거로 단독 사용하지 않는다.
