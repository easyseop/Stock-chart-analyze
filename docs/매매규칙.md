## 1단계 — 뇌: "이 종목이 매수 후보인가" (`gates.classify`)

8개 지표(추세·상대강도·신고가·시장·거래량·지지저항·RSI·추세선)로 **-100~+100 점수**를
매긴 뒤, 아래 **구조 기준**으로 분류한다. (점수는 판정 배지로 표시 — 현재 매수 게이트엔
직접 안 씀. 보조지표 다수결 필터는 §3 참조.)

### ❌ 아예 제외 (하나라도 걸리면 후보 탈락)
| 사유 | 기준(config) |
|---|---|
| 하락추세 / 방어선 이탈 | `vetoed` 또는 `entry_kind=avoid` |
| 동전주·부실 | `plan.junk` |
| 저유동성 | 일거래대금 미국 < **$1,000만**(`LIQ_MIN_USD`) · 한국 < **50억**(`LIQ_MIN_KRW`) |
| 이미 폭등 | 지수대비 RS **+40%↑** 또는 120일선 대비 **+40%↑** (`BLOWOFF_RATIO=0.40`) |

### 🟢 `now` = 지금 진입 (미러가 **실제로 사는** 등급) — 아래 전부 만족
- 전환 **3단계 이상** (돌파 후 안착/확정)
- 52주 범위 **하단 40% 이내** (`LOW_ZONE_NOW=0.40`)
- 손절폭 **< 12%** (`MAX_STOP_NOW=0.12`)
- 최근 3개월 **+25% 미만** (`RECENT_RUNUP_MAX=0.25`)

### 🟡 `watch` = 관찰 (아직 안 삼, 대기)
- 전환 1~2단계(임박·갓돌파) 또는 3~4인데 눌림/돌파 대기
- 하단 **50% 이내** (`LOW_ZONE_WATCH=0.50`) · 손절폭 **< 15%** (`MAX_STOP_WATCH=0.15`)

### 전환 4단계 (`analyze` transition_stage)
①임박 → ②갓 돌파(미확인) → ③돌파 후 안착(**3봉+**) →
④**확정**(돌파+안착+상승추세선+**거래량 1.3배**+RSI<70)

## 2단계 — 손: "지금 KIS에 실제로 주문 넣나" (`kis_buyloop`→`kis_buy.execute_entry`)

`now` 후보만 대상. 아래를 **순서대로 전부 통과**해야 1주라도 산다. 하나라도 막히면 skip.

| # | 관문 | 안 사는 경우 |
|---|---|---|
| 1 | 장중 | 미 정규장(22:30~05:00 KST)·한국 정규장 밖 |
| 2 | 어닝 회피 | 실적발표 D-3 이내 |
| 3 | 중복 금지 | 이미 KIS 보유 중(브로커 실잔고 재조회) |
| 4 | 쿨다운 | 당일 이미 매도한 종목 |
| 5 | 가격 괴리 | 현재가가 신호 진입가 **±1.5% 밖** (`ENTRY_TOLERANCE=0.015`) |
| 6 | 잔고 확인 | KIS 잔고 조회 실패 → 이번 사이클 전면 skip |
| 7 | 안전 게이트 8종 | ALLOW_BUY 봉인·kill-switch·부팅대사·파수꾼 생존·롤아웃(정규장·정수주·하루 신규 **10종목**)·계좌격리(기보유 denylist)·원장(잠금·간격) — `TRADE_STAGE=mirror`는 동시 보유 종목 수를 제한하지 않는다. 1·2차 leg와 거절은 같은 심볼이면 한 종목으로 세며, 실제 투입은 아래 예산 게이트가 별도로 제한한다. |
| 8 | 예산(사이징) | `min(현금, SEED−투입원가, 리스크 1%한도, 종목캡 1/3)` → 1주 미만이면 skip |

## 사이징 공식 (`bot/envelope.py`)
- 분모 = **고정 SEED**(`BOT_SEED_KRW`, 계좌 잔고 아님) — ※KIS 집행 기준. 웹 모의투자
  (autopaper)는 평가액(equity) 복리 사이징으로 다름(의도된 차이). 손익비 1:2는
  A 전략 기준(매물대 B는 최소 1.5)
- 리스크 = `risk_pct(1%) × SEED ÷ 주당 손절폭 × 가격`
- 종목캡 = `SEED × 1/3 − 이미 투입원가`
- 총량 = `min(봇현금, SEED − 봇 총 투입원가)`
- 최종 수량 = `min(위 전부) // 가격` (미확인 매수여력이면 0주 = fail-closed)

## 청산 규칙 (`scanner/autopaper.py` / 파수꾼 집행)
①하드 손절(손절가 −0.5×ATR 즉시) ②소프트 손절(손절가 2연속 확인) ③+1R 도달 시 절반
익절 + 잔량 본전 래칫 ④잔량 ATR 3배 트레일 ⑤21일 타임스탑 ⑥어닝 D-1 갭 회피

## 요약
- **살 때** = 뇌가 `now`로 뽑음(전환③+·저점권·좁은손절·급등아님) **AND** 장중·안겹침·진입가
  근처·슬리브 예산과 A+B 통합 운용한도·실제 매수여력이 남음.
- **안 살 때** = 위 중 **하나라도** 어긋남. 흔한 경우: 제외사유(하락추세/이미폭등), watch에
  머묾(전환 미확정·저점 아님), 진입가 놓침(±1.5%), 예산·현금 소진.
- 성격 = **보수적 필터의 연쇄**. 애매하면 **안 사는 쪽(fail-closed)**.
