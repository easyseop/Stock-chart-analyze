# 외부 평가 요청서 — 전략 A·B·B′(섀도) 설계 검토

작성: Claude, 2026-08-19 · 의뢰: 사용자
수신: 외부 평가자(GPT) · **산출물: 마크다운 파일 1개**

---

## 0. 당신에게 요청하는 것

1. **시장 실무 심층 조사** — 차트 기반으로 매매하는 전문가·트레이더·기관이
   아래 우리 전략과 같은 부류의 셋업을 실제로 어떻게 다루는지 조사한다.
2. **우리 설계와의 비교** — 우리 A·B·B′를 그 실무 표준과 대조해
   무엇이 정합적이고 무엇이 어긋나는지 판정한다.
3. **산출물** — 결과를 **마크다운 파일 하나로** 떨군다.

### 지켜야 할 것

- **출처 없는 수치를 쓰지 않는다.** 통계·연구를 인용하면 저자·연도·매체를 밝힌다.
  기억에 의존한 숫자는 "출처 불명"이라고 명시하라.
- **표본 한계를 숨기지 않는다.** 아래 실측은 매도 39건(B는 9건)뿐이다.
  이 표본으로 통계적 유의성을 주장하면 안 된다.
- **모의계좌 데이터다.** 체결이 실전보다 관대하다는 점을 감안하라.
- 우리 결론에 동의할 필요 없다. **반증이 목적이다.**

## 1. 시스템 개요

- 한국투자증권(KIS) **모의계좌** 자동매매. 국내주 + 미국주 동시 운용.
- 스캐너(GitHub Actions, 15분 주기)가 신호를 발행 → 서버(Oracle VM)의
  매수 루프가 KIS 시세·잔고로 재검증 후 직접 집행 → 파수꾼이 손절 감시.
- **사이징**: 1회 매매 손실 허용 = 계좌의 **1%**(`RISK_PER_TRADE = 0.01`),
  종목당 최대 비중 = 계좌의 **1/3**. 동시 보유 종목 수 상한은 없다.
- 시드는 고정. 월간 리뷰에서 실현손익을 반영해 수동 재설정(계단식 복리).
- 두 전략(슬리브) A·B는 **예산이 분리**돼 있고 신호 스트림도 분리돼 있다.

## 2. 전략 A — "전환 확정"(trend transition)

하락/횡보에서 상승으로 **전환이 확정된** 종목을 저점권에서 산다.

| 조건 | 임계값 | 코드 |
|---|---|---|
| 전환 단계 | **stage ≥ 3**(전환 확정/대기) | `gates.classify` |
| 52주 범위 위치 | **≤ 0.40** (하단 40% 이내) | `LOW_ZONE_NOW` |
| 최근 3개월 상승률 | **< +25%** (초과 시 '고점 추격'으로 제외) | `RECENT_RUNUP_MAX` |
| 손절폭 | **< 12%** (진입가 대비) | `MAX_STOP_NOW` |
| 보조지표 다수결 | 8개 모듈 중 **75% 이상 약세면 거부** | `CONSENSUS_BEAR_VETO` |
| 하드 제외 | 동전주·저유동성·실적발표 D-3·이미 폭등(RS 또는 120일선 대비 +40%) | `exclusion_reasons` |

`watch`(관찰) 그룹은 stage 1~2 또는 눌림/돌파 대기이며 **자동매수 대상이 아니다.**

## 3. 전략 B — "매물대 반등"(volume-profile shelf bounce)

거래량이 집중된 가격대(매물대) 위에서 **되돌아 오른 캔들**을 확인해 산다.
큰 손실 구간에서 지지가 살아 있는지를 본다.

| 조건 | 임계값 | 코드 |
|---|---|---|
| **추세 필터** | **없음 — 하락추세 veto를 의도적으로 적용하지 않는다** | `gates.classify_shelf` 주석 |
| 52주 범위 위치 | **0.10 ≤ rp ≤ 0.50** (하한은 2026-08-18 추가) | `SHELF_MIN_RANGE_POS`, `SHELF_LOW_ZONE` |
| 가격 위치 | 1년 볼륨프로파일의 **밸류영역 안**(VAL ≤ price ≤ VAH) | `_shelf_signal` |
| 머리 위 물량 | **≤ 55%** (현재가 위에 쌓인 거래량 비율) | `SHELF_OVERHEAD_MAX` |
| 최소 이력 | **504봉(≈2년)** (2026-08-18 추가) | `SHELF_MIN_HISTORY_BARS` |
| 반등 확인(5개 전부) | ①최근 3봉 저가가 POC까지 눌림 ②종가가 VAL 위 ③오늘 캔들 상단 마감 ④거래대금 평균의 1.1배 이상 ⑤20봉 신저가 아님 | `_shelf_signal` |
| 손절 | 반등 저점 × (1 − 2%) — 지지 붕괴 = 논리 무효 | `SHELF_STOP_BUF` |
| 목표 | VAH(밸류영역 상단) | |
| 최소 손익비 | **1.5** | `SHELF_MIN_RR` |
| 손절폭 상한 | **15%** | `SHELF_MAX_STOP` |
| 볼륨프로파일 구간 | 최근 **252일**(1년) | `LONG_PROFILE_DAYS` |

### 2026-08-18에 추가한 두 게이트의 배경(실측)

라이브 신호 19건을 실제 야후 데이터로 점검한 결과:

- **WLFC**: 범위 위치 **0.02**, 6개월 −71.8%, 1년 고점 대비 −76.7%,
  평균 보유자 손익 −63.5% → "저점권"으로 통과했다. 지지가 아니라 자유낙하.
  범위 게이트에 **상한만 있고 하한이 없었다.** → `SHELF_MIN_RANGE_POS = 0.10`
- **RHLD**: 상장 1.5년, 1년 +125.9% 뒤 고점 대비 −44.3% → **실제 매수 신호**로 나왔다.
  `lb = min(len(d), 252)` 때문에 짧은 이력이 조용히 "52주 범위"가 되고,
  매물대도 상장 이후 급등 구간으로만 구성된다. → `SHELF_MIN_HISTORY_BARS = 504`
- **307950(현대오토에버)**: 1년 **+203.5%**, 평균 보유자 손익 **+7.3%**
  → 후보 19건 중 유일하게 보유자가 이익. "물린 사람들의 매물대"가 아니라
  **상승 채널의 중간**이다. 매물대 논리가 성립하지 않는다.
  → 게이트는 아직 안 걸었고 **섀도 태그로만 기록**(아래 §5).

## 4. 실측 성과 (2026-08-18 기준, 확정 매도 39건)

| | 전체 | A(전환) | B(매물대) |
|---|---|---|---|
| 매도 | 39 | 30 | 9 |
| 승 / 패 | 26 / 13 | 23 / 7 | 3 / 6 |
| 승률 | 66.7% | **76.7%** | **33.3%** |
| 평균 수익률 | +4.27% | +5.90% | **−1.16%** |
| 평균 이익 | +8.16% | +8.64% | +4.43% |
| 평균 손실 | −3.51% | −3.13% | −3.95% |
| 손익비 | 2.33 | **2.76** | **1.12** |
| 손익분기 승률 | — | 26.6% | 47.1% |

- A는 손익분기 승률 대비 **50%p 여유**가 있다.
- B는 승률·손익비 **양쪽 모두** 열세다. 평균 이익이 A의 절반인데 평균 손실은 더 크다.
- **B 표본은 9건뿐이다.** 진짜 승률이 50%인 전략도 9번 중 3승 이하가 나올 확률이
  약 25%다. 통계적 결론을 내릴 수 없는 크기다.
- 관측 기간이 2주 남짓이고 그동안 시장은 대체로 상승·추세였다.
  **B의 본무대(횡보·박스)는 아직 관측되지 않았다.**

## 5. B′ — 제안 중인 섀도 전략 (아직 미구현)

B의 저조가 "표본" 때문인지 "설계" 때문인지 가르기 위한 **관측 전용** 병주안.
**실제 주문을 내지 않는다. 자본을 배정하지 않는다.** 신호만 생성해 기록하고,
같은 기간·같은 종목 풀에서 B와 성적을 비교한다.

| | 현행 B | B′(섀도) |
|---|---|---|
| 추세 | 필터 없음(하락 중 매수 허용) | **상승추세 필수**(예: 200일선 위) |
| 위치 | 52주 범위 하단(0.10~0.50) | 추세 내 **일시 되돌림**(예: 50일선/밸류영역) |
| 논리 | 물린 매물대의 지지 | 추세 중 일시 과매도 |
| 목표/손절 | VAH / 반등저점 −2% | 동일 구조 유지(비교 가능성 확보) |

함께 기록할 섀도 태그(현재 이미 신호에 실림, 판정에는 미사용):
`history_bars`(일봉 수), `holder_pnl`(평균 보유자 손익), `runup252`(1년 상승률).

## 6. 조사해 주기 바라는 항목

### 6-1. 실무 표준

1. **최소 상장 기간** — 볼륨프로파일·매물대·지지저항 기반 매매에서
   신규 상장주를 어떻게 다루는가? 배제하는가, 별도 패턴으로 다루는가?
   (인덱스 편입의 seasoning 관행, 오닐/IBD 계열의 IPO 베이스 취급 등)
2. **볼륨프로파일 구간 선택** — POC/밸류영역 계산에 실무자들은 어떤 기간을 쓰는가?
   구간 길이가 신호 품질에 미치는 영향에 대한 연구·통설이 있는가?
3. **하락 중 지지 매수 vs 상승 중 눌림목 매수** — 두 셋업의 기대값·승률에 대한
   실증 근거는 무엇인가? 어느 쪽이 표준으로 취급되는가?
4. **52주 범위 위치와 향후 수익률** — 저점권 매수 전략의 실증적 위치는?
   (52주 고점 효과 관련 연구를 포함해, 반대 방향 근거도 함께)
5. **손익비·승률의 실무 벤치마크** — 스윙 트레이딩에서 통상 어느 정도가
   "쓸 만한" 수준으로 간주되는가?

### 6-2. 우리 설계와의 비교·판정

각 항목에 대해:

- 우리 설계가 실무 표준과 **일치하는 부분** / **어긋나는 부분**
- 어긋나는 부분이 **의도적 차별화인지 설계 결함인지**에 대한 당신의 판단과 근거
- 특히 **B가 추세 필터를 의도적으로 끈 것**에 대한 평가
- **B′가 B보다 나을 것으로 기대할 근거가 실제로 있는지** (없으면 없다고 말할 것)

### 6-3. 개선 제안

- 지금 표본(A 30건 / B 9건)으로 **정당화될 수 있는 변경**과
  **더 많은 데이터가 필요한 변경**을 구분해서 제시할 것.
- 우리가 놓치고 있을 만한 **다른 전략 계열**이 있다면 제시하되,
  기존 인프라(일봉·볼륨프로파일·KIS 조회 한도 초당 2회)로 구현 가능한 것 위주로.

## 7. 산출물 형식

파일명: `STRATEGY_REVIEW_BY_GPT.md`

권장 구성:

```
1. 요약 판정 (3~5줄)
2. 실무 표준 조사 결과 (항목별, 출처 포함)
3. A 전략 평가
4. B 전략 평가
5. B′ 제안 평가 — 기대 근거 있음/없음
6. 개선 제안 (지금 가능 / 데이터 필요)
7. 우리 분석에 대한 반론 (동의하지 않는 지점)
8. 출처 목록
```

**7번(반론)을 비워두지 말 것.** 동의만 하는 검토는 가치가 없다.
