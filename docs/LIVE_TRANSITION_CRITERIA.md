# 실계좌(KIS live) 전환 기준 — 사전 등록 (2026-08-07)

> **왜 지금 정하나**: 기준을 성과를 본 뒤에 정하면 반드시 자기합리화가 섞인다.
> 이 문서는 모의 성과가 쌓이기 **전에** 숫자를 고정하는 사전 등록(pre-registration)이다.
> 게이트를 전부 통과해도 **자동 전환은 없다** — KIS live 전환·증액은 언제나
> 사용자의 명시적 승인이 별도로 필요하다(기존 승인 체계 유지).

측정 시작일: **2026-08-06** (L0 미국 본장 첫 직접집행 — PAAS·BX·IDXX·MKC…).
벤치마크: 나스닥(주 벤치), KR 보유 발생 시 코스피 병행 표기.
성과 척도: 계좌 TWR − 벤치마크 TWR = **알파** (기존 alpha 파이프라인).

## 1. 전환 게이트 — 전부 충족해야 "소액 라이브 논의"를 시작할 수 있다

| # | 게이트 | 기준(숫자) | 근거 |
|---|---|---|---|
| G1 | 측정 기간 | 시작일부터 **최소 3개월** (2026-11-06 이전 판정 금지) | 한 국면짜리 운(강세장 순풍)을 배제할 최소 기간 |
| G2 | 표본 | 청산 완료 트레이드 **≥ 40건** | 기대값 부호를 논할 최소 표본 |
| G3 | 알파 | 측정기간 전체 알파 **> 0%p** + 산출 구간에 미해결 품질 이벤트 0 | 지수를 못 이기면 지수를 사는 게 맞다 |
| G4 | 최대낙폭 | 계좌 TWR 기준 MDD **≤ 15%** | 건당 1% 리스크 구조에서 이걸 넘으면 상관 리스크 관리 실패 |
| G5 | 운영 무사고 | 판정 직전 30일: 수동 개입이 필요했던 주문 사고(UNKNOWN 방치·이중매도·미회계 체결) **0건**, kill 자동상향 원인 미해결 **0건** | 실계좌에서 처음 겪는 사고는 수업료가 아니라 손실이다 |
| G6 | 손절 준수 | 청산 전수 중 체결가가 손절 기준 −1.5%를 초과 이탈한 비율 **≤ 5%** (미국 chase floor −3% 설계 감안, 하한가 등 구조적 예외는 기록으로 소명) | 손절이 안 지켜지는 시스템은 리스크 1%가 거짓말이 된다 |
| G7 | TWR 정식 검토 | 판정 전 TWR 파이프라인 적대 검토 1회 **P0/P1 = 0** | 기존 합의(2026-08-06): TWR 수치가 전환 결정에 쓰이기 전 검토 필수 |

## 2. 통과 후 전환 방식 — 한 번에 가지 않는다

| 단계 | 규모 | 유지 조건 | 다음 단계 조건 |
|---|---|---|---|
| 0 (현재) | KIS mock 100% | — | G1~G7 전부 충족 + 사용자 승인 |
| 1 | live **총 시드의 10%** | MDD ≤ 15%, 주문 사고 0 | 최소 1개월 + 라이브 알파 ≥ −1%p(슬리피지 허용오차) + 사용자 승인 |
| 2 | live 30% | 동일 | 최소 3개월 + 알파 > 0 유지 + 사용자 승인 |
| 3 | live 100% | 동일 | — |

**강등 규칙**: 어느 단계든 MDD 15% 초과 또는 주문 사고(P0) 발생 → 신규 매수 즉시
차단(보호 매도는 유지)하고 직전 단계로 축소. 재승격은 해당 단계 조건을 처음부터.

## 3. 기준 변경·시계 리셋 규칙

- 이 문서의 숫자는 성과 데이터를 본 뒤에는 **완화 방향 변경 금지**(강화만 허용).
  완화가 필요하면 사유를 리뷰 문서로 남기고 **측정 시계(G1·G2)를 리셋**한다.
- 진입 로직 변경의 취급:
  - 리스크 감소·기록 추가(손절 트리거 하드닝, 투입 상한, 국면/MFE/MAE 태그,
    슬리피지 기록)는 **리셋 없이 허용** — 기대값을 만드는 규칙이 아니라 지키는 규칙.
  - 신호·게이트의 기대값에 영향 주는 변경(국면 필터 **발동**, 진입 조건 수정)은
    변경 시점부터 **G1·G2 재시작**.
- 판정은 월간 성과 리뷰에서 게이트 체크리스트로 갱신하고, 전부 충족한 달에
  전환 검토를 연다.

## 4. 부록 — 보류 중 리스크 개선 TODO (2026-08-07 사용자 지시로 보류)

착수는 각각 사용자 승인 후. 1·3은 매매 로직 변경이라 구현 후 적대 검토 필수.

1. **손절 트리거 하드닝** — bid 확인 + 확인 틱(국내 포함), 하한가 잠김 감지 시
   재주문 금지+P0 경보(대기열 순번 보존). 플래시 크래시/이상 호가 방어.
2. **국면·MFE/MAE 섀도 태그** — 진입 시 지수 국면과 보유 중 MFE/MAE 기록만
   (발동 없음). 국면 필터·출구 개선의 실측 근거 축적.
3. **하루 슬리브 투입 상한** — 하루 예산 1/3까지만 신규 투입(진입 뭉침 분산).
4. **하한가·슬리피지 실측 준비** — 하한가 근접 경보 + 신호가 vs 체결가 차이
   원장 기록(모의 성과의 슬리피지 보정 근거, 단계 1 진입 전까지).
