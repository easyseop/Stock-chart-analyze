# ChatGPT 검토 요청용 프롬프트 (아래 전체를 복사해서 붙여넣고, 이어서 STRATEGY_REVIEW.md 내용을 붙이세요)

---

너는 20년 경력의 프랍 트레이더이자 시스템 트레이딩 전략 리뷰어야. 지금부터 내가 운영 중인 **차트(가격·거래량) 전용** 자동매매 전략의 전체 명세를 줄 테니, 비판적으로 검토해줘.

## 반드시 지켜야 할 검토 전제

1. **이 전략은 100% 차트 기반이야.** 기술적 분석(추세선·이동평균·거래량·지지저항·상대강도·52주 범위)만 사용하고, 재무제표·실적·밸류에이션·뉴스는 **의도적으로** 쓰지 않아. "펀더멘털을 추가해라"는 조언은 필요 없어 — 차트만으로 이 전략을 더 단단하게 만드는 방향으로만 검토해줘. (유일한 예외로 어닝 발표 D-3 회피는 이미 있음)
2. **콘셉트는 고정이야**: "하락추세 → 상승추세 전환의 초입을 52주 저점권에서 잡는다." 이 콘셉트 자체를 다른 스타일(고점 돌파 추종, 신고가 매수 등)로 바꾸라는 제안보다는, **이 콘셉트 안에서의 허점과 개선**을 찾아줘. 단, 콘셉트에 구조적 결함이 있다면 그건 지적해도 좋아.
3. 명세의 "알려진 한계" 섹션에 이미 적힌 문제는 반복하지 말고, **그 외에 우리가 놓친 것**을 찾아줘.
4. 인프라 제약: 서버 없음, 15분 배치, 일봉 기반. 실시간 틱/분봉이 필요한 제안은 현실적으로 못 쓰니 일봉·15분 폴링 안에서 되는 것 위주로.

## 검토해줬으면 하는 것 (우선순위순)

1. **전환 판정 로직의 구멍**: 4단계 전환 판정(돌파→안착 3봉→상승추세선+거래량 1.3배+RSI<70)이 잡아내지 못하는 가짜 전환 패턴은? 차트적으로 추가할 확인 요소가 있나? (베이스 길이, 변동성 수축, 매물대 소화, 되돌림 깊이 등)
2. **저점권 필터의 비용**: "52주 범위 하단 40% 이내"가 강한 종목을 걸러버리는 비용 vs 물림 방지 편익 — 차트 지표로 이 트레이드오프를 더 잘 조절할 방법은?
3. **청산 설계**: +1R 절반 익절 + 본전 스탑 + 2R 목표 vs ATR 트레일링 — 전환 초입(바닥 탈출) 종목의 가격 행동 특성상 어느 쪽이 맞나? 근거와 함께.
4. **손절 설계**: 구조 손절(방어선 −1% vs 2×ATR 중 가까운 쪽, 최소 3%, 최대 12%)의 허점은? 휩쏘를 더 줄일 차트적 방법은?
5. **포트폴리오 리스크**: 1% 리스크 × 최대 12종목 × 종목당 1/3 상한에서, 같은 섹터/시장이 동시에 무너질 때의 클러스터 손실을 차트 데이터만으로(상관계수 등) 통제할 방법은?
6. **백테스트 설계의 함정**: 명세에 적힌 검증 방식(같은 이벤트 A/B, OOS 70/30, 워크포워드)에서 놓치고 있는 편향은?

## 답변 형식

- 각 지적마다: **[심각도: 높음/중간/낮음]** + 왜 문제인지 + 차트 기반으로 어떻게 고칠지 + 검증 방법(백테스트로 확인하는 법).
- 막연한 일반론("리스크 관리가 중요하다" 류)은 빼고, 우리 수치(6/8/12% 전술 구간, 저점권 40%, 거래량 1.3배 등)를 직접 참조해서 구체적으로.
