# 전환 스크리너 + 자동매매 — 지표 기준·매매 전략 전체 명세

> 이 문서는 외부 리뷰(다른 LLM/트레이더)용 자기완결 명세입니다.
> 아래 수치는 전부 실제 운영 코드의 값 그대로입니다(요약·각색 없음).
> 목적: 빠진 관점·과최적화·논리 구멍·개선 아이디어를 지적받기 위함.

## 0. 시스템 한 줄 요약

**"하락추세 → 상승추세 전환의 초입을 저점권에서 잡는" 일봉 기반 스크리너**와,
그 추천을 그대로 집행하는 **자동 모의투자(시드 1억)**.
서버 없음 — GitHub Actions가 장중 15분마다 일봉을 갱신·분석·매매 시뮬레이션하고
정적 사이트(GitHub Pages)와 텔레그램으로 내보낸다.

- 유니버스: S&P500 전체(~503) + 한국 우량주(~302) ≈ 800종목
- 데이터: 일봉(2019~, FinanceDataReader) + 상위 80종목 60분봉(보조)
- 미완성 봉 제외(`DROP_UNCLOSED_BAR=True`) — 신호가 봉 진행 중에 뒤집히지 않게

## 1. 지표 기준 — "전환 후보"를 어떻게 정의하는가

### 1-1. 하락추세선과 돌파 (핵심 신호)

- 추세선: 최근 180일에서 스윙 피벗(좌우 5봉 극값) 기반, **최소 3터치**(앵커 2 + 추가 1),
  앵커 간 최소 20봉 — 4~5봉짜리 잡선 배제.
- 돌파 인정: 선 대비 **+0.5% 이상**(노이즈 돌파 제외) + **거래량 평균 1.5배 이상 동반**.
  거래량 미동반 돌파는 백테스트에서 기대값 음(-)이라 격하.
- 현재가에서 12% 넘게 떨어진 선은 낡은 선으로 무시.

### 1-2. 전환 4단계 (진행도)

| 단계 | 정의 |
|---|---|
| ① 임박 | 하락추세선 저항에 근접(±2%) |
| ② 갓 돌파(미확인) | 돌파했으나 안착 전 — 되밀림 위험, 관망 |
| ③ 돌파 후 횡보(대기) | 돌파 후 선 위에서 **최소 3봉 안착** |
| ④ 전환 확정 ⭐ | ③ + **상승추세선(저점 높아짐) 형성** + 진입봉 거래대금 ≥ 평균 1.3배 + **RSI < 70** |

④의 콤보 게이트(거래량 1.3× + RSI<70)는 자체 백테스트에서 기대값 최고
(+0.23R, Profit Factor 1.40)였던 조합.

### 1-3. 하드 제외 게이트 (모든 추천 공통 — 하나라도 걸리면 탈락)

1. 하락추세 지속/방어선 이탈 (`DOWNTREND_VETO`)
2. 동전주: 미국 $1 미만 / 한국 1,000원 미만
3. 심한 부실: 52주 고가 대비 **−85% 이하** (떨어지는 칼날)
4. 저유동성: 20일 평균 거래대금 미국 $10M / 한국 50억원 미만
5. 이미 폭등: 지수 대비 상대강도 또는 120일선 이격 **+40% 이상**
6. 고점 추격: 최근 3개월 **+25% 이상** 상승분은 '지금 진입' 제외
7. **저점권 게이트**: 52주 저가~고가 범위에서 현재가 위치(0=최저점)가
   '지금 진입'은 **하단 40% 이내**, '관찰'은 50% 이내여야 함
8. 손절폭 과대: '지금 진입' **12% 이상** / '관찰' 15% 이상이면 탈락
9. 어닝 발표 D-3 이내면 신규 진입 금지(갭 리스크)

게이트는 순차 통과(OR 입구 금지)이고, 빌드마다 `audit()`이 결과 불변식을
재검사해 위반 시 **배포 자체를 차단**한다 (손절≥진입, 눌림 진입가>현재가,
저점권 위반 추천 등 과거 회귀 사례를 전부 불변식화).

### 1-4. 체크리스트 6항목 (추천 강도, ⭐는 4/6 이상)

1. 전환 단계 ≥ ③
2. 시장(지수)이 상승 방향 (S&P500 / KOSPI 50일선 기준)
3. 상대강도 > 0 (3개월 지수 대비 아웃퍼폼)
4. 52주 고가 대비 −50%~−15% 구간 ("많이 빠졌다 도는 중" — 상승 여력)
5. 추격 아님 (지지 근처 타점)
6. 종합점수 ≥ +20 (아래 1-5의 정규화 점수)

### 1-5. 종합점수 (참고 지표, 게이트 아님)

모듈: 이평배열/다중TF(trend), 상대강도(rs), 신고가(newhigh), 시장방향(market),
거래대금(volume), 지지저항(sr), RSI, 추세선(trendline).
ADX로 국면(추세장 ≥25 / 횡보장 <20 / 전환)을 나눠 가중치를 바꾼다 —
모멘텀 계열(RS 1.2, 시장/거래량 0.8~1.0) 우대, 역추세 계열(RSI 0~0.4) 축소.
−100~+100 정규화, |점수| ≥50 적극 / ≥20 관심.

### 1-6. 진입가·손절가·목표가 산출

- **진입가**: 현재가(즉시) 또는 눌림 지정가(1차 반등구간 지지 중심, 손절가보다 위일 때만)
- **손절가**: 구조 기반 — 방어선(지지) −1% 버퍼 vs 진입 −2×ATR(14) 중
  **진입가에 가까운 쪽**(`STOP_MODE=nearest`). 최소폭 3%(휩쏘 방지).
- **목표가**: 진입 + 2×손절폭 (**손익비 1:2 고정**)

## 2. 진입 전략

### 2-1. 추천 그룹

- **now(지금 진입)**: 단계 ≥③ + 저점권 40% + 손절폭 <12% + 추격 아님
- **watch(곧 올 자리)**: ①·② 또는 ③·④인데 눌림/돌파 대기

자동매매는 **now 그룹만** 매매. 갓 전환(추세선 위 +5% 이내 = "신선") 우선.

### 2-2. 진입 전술 3구간 — 손절폭이 전술을 정한다

손절가는 구조로 고정 → 진입가가 손절가에 가까울수록 같은 1% 리스크로
포지션이 커져 손익비가 좋아진다는 원리.

| 손절폭 | 전술 |
|---|---|
| ≤ 6% | ⚡ 즉시 전량 |
| 6~8% | ⚖ 절반 즉시 + 절반 눌림 지정가 |
| 8~12% | ⏳ 눌림 지정가만 (추격 금지) |

눌림 지정가는 손절선 이탈 시 취소(추세 훼손), 21일 미체결 시 만료(놓침≠손실).

> 임계 튜닝 이력: "눌림 승률 우위(63.8%)"로 보여 6/8→5/7로 옮겼다가,
> **같은 이벤트 A/B 백테스트**에서 그것이 선택 편향임이 드러남
> (즉시 −0.03R > 눌림 −0.12R, 눌림은 31%가 미체결로 승자를 놓침) → 원복.
> 표본 153건이 작아 300종목 포워드 데이터가 쌓이면 재검토 예정.

### 2-3. 포지션 사이징 — 두 상한 중 빡빡한 쪽

1. **리스크 사이징**: 수량 = 총자산 × **1%** ÷ 주당 손절폭 (반 타프 R 기반)
2. **비중 상한**: 한 종목 투입 원가 ≤ 총자산의 **1/3** (보유+대기 주문 합산)
   — 사이징에서 1차 차단 + 빌드마다 감사 함수가 사후 재검증(위반 시 로그·공개 JSON에 기록)

추가 제약: 동시 보유(대기 포함) 최대 **12종목**, 총 투자 한도 **85%**(현금 버퍼 15%),
지정가 대기 금액은 '예약'으로 잡아 주문가능금액 개념 유지.

**운영 안전장치(상시, 빌드마다 사후 감사)**: 하루 신규 진입 ≤3 / 일일 실현손실
−2% 서킷브레이커 / 손절 후 재진입 쿨다운(당일+익거래일) / 대기 주문 신호 부패
재검사(제외 게이트·어닝 D-3 재확인 후 취소) / USD-KRW 환율 일 1회 갱신.

## 3. 청산 전략 (분할익절 + 래칫 손절)

| 시점 | 행동 |
|---|---|
| 손절가 −0.5ATR 이탈 | **하드 — 즉시 전량**(급락 방어) |
| 손절가 이하 2연속 폴링(≈30분) | **소프트 — 전량 손절** (스파이크 휩쏘 방지, 분할 손절 금지) |
| **+1R 2연속 확인** | **절반 익절** + 손절 → 본전 이동 (터치 1회로는 미발동) |
| +1R 이후 잔량 | **ATR 트레일 래칫**: `새 스탑 = max(기존, 최고가−3×ATR진입시점)`, 고정 목표 캡 없음 |
| 어닝 D-1 | MFE<0.5R 전량 / 0.5~1R 절반 축소 / +1R 달성 시 통과 허용 |
| 15거래일 내 +1R 미도달 | 타임 스탑 전량 정리 (전환 실패는 시간으로도 드러남) |

- **래칫 원칙**: 손절은 절대 아래로 내리지 않는다(가격 갱신에 따른 손절 확대 금지).
- 결과 분포 설계: 최악 −1R / 흔함 +0.5R / 좋음 +1.5~3R+.
- 잔량 트레일의 근거(자체 A/B/C, 같은 진입 174건): 트레일 무제한 +0.131R >
  본전+2R 캡 +0.120R > 트레일+2R 캡 +0.117R — "트레일과 고정 목표를 같이 쓰면
  2R 직전에 끊어먹어 최악"이 데이터의 결론.
- 당일 손절 종목 재진입 금지(churn 방지), 일일 실현손실 −2% 도달 시 신규 중지(실거래 봇).

참고한 매매법: 반 타프 R-멀티플·1% 사이징 / 오닐 7~8% 하드 손절·시장방향 필터 /
미너비니 분할 익절+본전 스탑(free ride) / 와인스타인 스테이지 전환(Stage 1→2).

## 4. 운영 파이프라인 (배치·가격·알림)

- **가격 갱신**: 한국 장중(09:00~15:30 KST)·미국 장중 각 **15분마다** GitHub Actions 빌드.
  마감 후 1회 전체 백필. 일봉 기반이므로 장중 값은 "오늘의 미완성 봉 현재가".
- **자동매매 판정 시점**: 매 빌드. 장 열린 시장의 종목만 진입/청산(닫힌 시장 가격은
  움직이지 않으므로 체결 금지 — 주말·야간 종가로 가짜 체결하던 버그를 수정한 규칙).
- **알림 2계층**:
  - 자동매매 체결 = 상세(수량·체결가·손절·목표·전술·사유·손익·R)
  - 매수/도달 제안 = 간단(종목명·진입/손절·전술 한 줄) + 장중 시장만 + 회당 상한(매수 8·도달 6)
- **신뢰성 장치**: 상태파일 원자적 저장(+.bak 복구) / 추천 불변식 audit로 배포 차단 /
  워치독(30분마다 라이브 신선도 검사, 정체 시 자동 재빌드+텔레그램 경보) /
  매수 사유(신선도·단계·저점권·체크·손절폭)를 전 건 기록 → 전술·신선도별 승률 자동 집계,
  계획(진입/손절) 대비 실제 체결 편차(슬리피지)도 집계.

## 5. 알려진 한계 (스스로 인지하고 있는 것)

1. **15분 갭**: 빌드 사이에 손절가를 찍고 반등하면 미체결, 급락하면 손절가보다
   낮은 체결(슬리피지가 자연 모델링되는 셈). 서버리스 구조의 트레이드오프.
2. **표본 부족**: 청산 완료 트레이드가 아직 적어 전술별 승률·임계 튜닝은
   과최적화 위험 → 포워드 데이터 축적 전까지 기본값 고정 방침.
3. 일봉 기반이라 장중 변동성(VWAP, 분봉 구조) 미사용. 60분봉은 보조 표시만.
4. 펀더멘털 무개입(차트 전용) — 부실 필터는 가격·유동성 프록시뿐.

## 6. 리뷰어에게 묻고 싶은 것

1. "하락→상승 전환 초입 + 저점권 40%" 콘셉트 자체의 구조적 약점은?
   (예: 저점권 필터가 강한 주도주를 걸러버리는 비용 vs 물림 방지 편익)
2. 전환 확정(④)의 콤보(3봉 안착 + 상승추세선 + 거래량 1.3× + RSI<70)에서
   빠진 확인 요소가 있는가? (예: 베이스 길이, 수축 패턴, 매물대 소화)
3. 손절폭 기반 전술 3구간(6/8/12%)과 1:2 고정 손익비 — 변동성(ATR%) 기반
   동적 목표가 더 나은가?
4. 잔량 트레일 폭 3×ATR(진입 시점 고정)의 근거가 약하다 — 샹들리에(최고가 기준
   재계산 ATR)나 변동성 적응형(폭을 ATR% 구간별로) 대비 장단점은? 전환 초입
   종목의 바닥 탈출 후 변동성 확대 특성을 고려하면?
5. 종목당 1/3 상한 + 최대 12종목 + 1% 리스크 조합의 포트폴리오 수준 리스크
   (상관·동시 손절 클러스터)를 더 통제할 방법은?
6. 15분 일봉 폴링 구조에서 놓치는 것 중 우선순위가 가장 높은 개선은?
