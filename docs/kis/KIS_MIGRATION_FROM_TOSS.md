# 토스 → KIS 전환 재계획 (설계 델타)

> 2026-07-10. 우리는 토스 실주문 설계(`docs/live_design/00~07`, `docs/TOSS_API_*`)를 이미
> 27태스크 + Codex 리뷰 + 계좌격리 분석까지 끝냈다. 브로커를 **KIS(한국투자증권)**로 바꾼다.
> 이 문서는 **"처음부터 다시"가 아니라 델타(무엇이 바뀌고 무엇이 그대로인가)** 만 다룬다.
> 사실 근거는 `docs/kis/KIS_API_READINESS.md`. 읽는 법: `##` 하나씩 끊어 읽기.

---

## 0. 왜 바꾸나 (한 문단)

토스 브로커계좌를 **봇 전용으로 2개째 개설할 수 없어** 시드 물리격리가 막혔다. KIS는 **1
appkey=1계좌**라 봇 전용 계좌에 별도 키를 물리면 격리가 자연 성립하고, **개인계좌는 IP
allowlist가 없으며**(토스 최대 골칫거리 소멸), **진짜 모의투자(paper) 환경**이 있어 실돈 전
주문·체결·대사를 검증할 수 있다. 대신 **미국주 서버측 조건/스톱주문이 없고 연속장 시장가가
없다** — 그러나 우리 손절은 원래 파수꾼 중심이고 0차 방어(조건주문)는 이미 "보조"로 강등돼
있어 **설계가 이 약점을 이미 흡수**한다. 순득으로 판단.

## 1. 그대로 두는 것 (브로커 무관 — 재작성 금지)

이 계층들은 **한 줄도 다시 안 짠다.** 어댑터만 바뀐다.
- **전략·엑싯**: 52주 저점권 진입·ATR 손절·R배수 엑싯(+1R 반익절·본전스톱·ATR 트레일·2연속
  확인·21일 타임스톱)·사이징(RISK_PCT·POS_CAP). → 시세·주문 브로커와 무관.
- **주문 원장**(`bot/ledger.py`): 상태기계·UNKNOWN 잠금·대사·잔여만 재주문. **오히려 KIS에서
  더 중요**(클라 멱등키가 없으므로).
- **파수꾼 골격**(`bot/sentinel.py`): 포지션 정체성 멱등키·dry-run·원장연동.
- **시드 봉투·계좌격리**(`07_ACCOUNT_ISOLATION_BUDGET.md` IS2~IS5): SEED 사이징·심볼 비중첩·
  비대칭 대사·동결. **버그 2개(equity 사이징·총량 게이트)는 KIS에서도 그대로 수정 대상.**
- **인프라**(`04_INFRA_GATES.md`): 상시 서버·dead-man·kill-switch·단계적 롤아웃 가드·환경분리.
- **알림**(`bot/notify.py`), **CF Worker**, **테스트 하네스**(05 파일).

## 2. 어댑터 교체 — `bot/toss.py` → `bot/kis.py` (신규, 델타의 90%)

| 항목 | 토스 | **KIS 델타** |
|---|---|---|
| 토큰 발급 | `POST /oauth2/token` form | **`POST /oauth2/tokenP` JSON** body(appkey/appsecret) |
| 토큰 수명 | 24h·즉시 무효화 | 24h·**6h 내 동일 토큰 재반환**·**발급 1분당 1회**(단일캐시 강제↑) |
| 인증 헤더 | `Authorization`+`X-Tossinvest-Account`(accountSeq) | `authorization`+`appkey`+`appsecret`+**`tr_id`**+`custtype:P`. 계좌는 **body/query**(CANO+ACNT_PRDT_CD) |
| IP allowlist | **강제**(403·VPS IP 관리) | **개인 불필요** — 관련 코드·운영부담 삭제 |
| 시세 | `/api/v1/prices` | `/uapi/overseas-price/.../price`(모의 분봉·10호가 미지원 주의) |
| 매수여력 | `/buying-power?currency=` | `inquire-psamount`(**모의 미지원**→잔고 계산 분기)+`foreign-margin.itgr_ord_psbl_amt` |
| 매도가능수량 | `/sellable-quantity` | 별도 API 없음 → **`inquire-balance.ord_psbl_qty`** |
| 에러 분류 | HTTP status×code | **`rt_cd`/`msg_cd`(EGW·MCA)** 기준 `classify_error()` 재작성 |
| 멱등키 | `clientOrderId`(10분) | **없음** → 자체 합성 대사키 + 원장 |

→ **TR_ID 매핑 테이블**(어댑터 계약의 핵심, `(env×시장×액션)`):

```
US 매수:     실전 TTTT1002U → 모의 VTTT1002U
US 매도:     실전 TTTT1006U → 모의 VTTT1001U   ← ★비대칭! 접두 스왑 금지
US 정정취소: 실전 TTTT1004U → 모의 VTTT1004U
US 잔고:     실전 TTTS3012R → 모의 VTTS3012R
US 체결내역: 실전 TTTS3035R → 모의 VTTS3035R
US 미체결:   TTTS3018R (모의 지원)
체결통보WS:  실전 H0GSCNI0 → 모의 H0GSCNI9
```
`"V"+tr_id[1:]` 같은 기계적 치환 **금지** — 위 표를 상수로 박는다.

## 3. 매수 실행·사이징·환전 (X1·X2·X3) — 델타

- **X1 매수 실행기**: 엔드포인트/필드만 교체(`POST .../overseas-stock/v1/trading/order`,
  매매구분은 body 아니라 **tr_id로 결정**, `OVRS_EXCG_CD`·`PDNO`·`ORD_QTY`·`OVRS_ORD_UNPR`·
  `ORD_DVSN=00`). 응답 `ODNO`를 원장에 저장(정정/취소·대사 핸들).
- **X2 사이징**: 로직 불변(07 파일 IS4의 **고정 SEED 분모**·총량 게이트 — 버그 수정 포함).
  매수여력은 하향 클램프로만. **모의는 `inquire-psamount` 미지원** → 잔고 기반 클램프로 분기.
- **X3 환전**: **통합증거금 신청 시 사실상 제거** — 원화 시드로 미국주 직접 매수, 자동환전.
  단 **미수/신용 아님 확인**이 게이트(현금 원칙). 미신청 계좌는 사전환전 경로로 분기 유지.
  → 토스 설계 대비 **태스크 축소**(조건부).

## 4. 손절·보호 (X4·P1·P2·L6) — **가장 큰 델타**

- **0차 방어(조건주문) 삭제**: 미국주 서버측 조건/스톱/OCO 없음 → **P1(조건주문)·B0 계층을
  미국에선 제거**. `supports_server_side_stop`를 시장별 플래그로(국내 true·미국 false).
- **파수꾼이 1차이자 최후**: `bot/sentinel.py` 실매도를 채우되 —
  - **시장가 금지**(연속장 시장가 부재). **마켓터블 지정가**(`ORD_DVSN=00`, 현재가−슬리피지
    버퍼)로 발주 + **미체결 chase**(재던지기)·슬리피지 상한·부분체결 잔여 처리를 원장에 반영.
  - 매도 상한은 `min(봇 원장 claim, inquire-balance.ord_psbl_qty)`(07 IS4·IS5 그대로).
- **파수꾼 생존성 상향**(0차 방어가 없어졌으니): 상시 호스트 하트비트·워치독 재기동·프로세스
  격리를 **토스 때보다 강하게**. 매수 직후 보호 SLA는 "조건주문 등록" 대신 "**파수꾼 감시 등록
  확인 + stop 원장 기록**"으로 재정의.
- **P2 보호 커버리지 감시**: 유효. 단 감시 대상이 "조건주문 존재"가 아니라 "파수꾼이 이 종목을
  stop과 함께 감시 중인가 + 하트비트 신선한가"로 바뀜.

## 5. 대사·멱등 (O1~O4) — 델타

- **O1 원장 확장**: 토스 `clientOrderId`/10상태 대신 **KIS `ODNO`·합성 대사키·`rt_cd` 상태**로.
  포지션 정체성 멱등키는 우리 원장 소유(불변).
- **O2 주문 primitive**: 생성/조회/취소를 KIS 엔드포인트로(정정취소 `order-rvsecncl`,
  `ORGN_ODNO` 필수).
- **O3 체결 폴링 + O4 부팅 대사**: **nccs(미체결)+ccnl(체결내역) 둘 다** 조회하는 대사 루프.
  타임아웃=재주문 금지·조회 우선(불변, KIS에선 유일 방어라 더 엄격). **체결통보 WS(H0GSCNI0)**
  를 대사 1차 채널로 추가하면 폴링 부하↓(선택).
- **CO1(조건주문 primitive)**: 미국 대상이면 **삭제/보류**(서버측 없음). 국내 확장 시에만.

## 6. 시드 격리 (07 파일) — KIS에서 더 깨끗해짐

- **IS1-A(별도 계좌 물리격리)가 정공법으로 성립**: 봇 전용 계좌 개설 + **그 계좌 전용 appkey**
  발급(모의 2계좌·실전 89계좌 한도 내). holdings/잔고/주문이 **키 단위로 완전 분리** → 토스에서
  걱정하던 "봇 키가 사용자 손실 계좌까지 주문" 위험이 **키↔계좌 1:1이라 구조적으로 차단**.
- 결과: **IS2~IS5(공유계좌 논리격리)의 복잡도 대부분 불필요**해질 수 있음. 단 **버그 2개
  (equity 사이징·총량 게이트) 수정과 고정 SEED 봉투는 별도 계좌든 공유든 그대로 유지**.
- [실측 VA]가 "봇 전용 계좌 개설 가능?"에서 **"모의 계좌 발급 + 실전 봇 계좌 개설"로 대체** —
  KIS는 개설·키발급 절차가 명확해 실측 부담이 낮음.

## 7. 시세·세션·게이트 (L1~L6·I1) — 델타

- **모의 시세 공백 반영**: 분봉·10호가·현재가상세 모의 미지원 → **시세 소스와 주문 소스 분리**.
  시세는 실전키/외부피드, 모의는 주문·대사 전용(§KIS_READINESS §3·§10).
- **세션·캘린더**: 미국 정규장 + **주간거래(daytime, 모의 미지원·지정가만)** 두 축. 진입 게이트는
  세션 인지 유지. 종목 상태(상장폐지·정지)는 KIS 조회 API로 매핑.
- **레이트리밋**: 그룹 버킷 → **초당(실전 20·모의 2)** 중앙 리미터로 재구성. **모의 2/s가 빡빡**
  하므로 준실시간 폴링은 실전/외부로, 모의는 저유량 검증.

## 8. Stage 게이팅 재정의 (모의를 앞단에 삽입 — 토스엔 없던 이점)

| Stage | 토스 | **KIS** |
|---|---|---|
| 0 | 시세 읽기(가상) | 동일 + KIS 모의키 발급 |
| 1 | +계좌 조회·대사(가상) | **+모의계좌 잔고·미체결·체결내역 대사(실 API·가상돈)** |
| 1.5 | 주문 primitive 실측(수동 1건) | **모의에서 주문·체결·정정취소·대사 전 경로 검증**(지정가) |
| 2 | 자동 실주문 소액 | 봇 전용 실계좌 소액(시장가·매수여력·주간거래 등 모의 미검증분 실측) |

→ **핵심**: KIS는 **Stage 1.5의 대부분을 모의(가상돈)로** 소화 가능 → 실돈 리스크가 토스보다
크게 낮다. 단 모의 미지원분(시장가 손절·매수여력·분봉·주간거래·예약조회)은 **Stage 2 실전에서만**
검증된다는 걸 회귀 계획에 못박는다.

## 9. 온보딩 체크리스트 (실행 순서)

1. **KIS 계정 준비**: 한국투자증권 계좌 + 앱. **모의투자 참가신청**(리그: **국내주식+해외주식** —
   유니버스 95% 미국주라 필수) + 접속 비밀번호(공유 금지) 설정.
2. **해외주식 거래 신청 + 통합증거금 신청**(원화 미국주 매수 원하면; 신용성격 모의로 확인).
3. **KIS Developers 서비스 신청** → **모의용 appkey/appsecret** 발급(실전과 별도).
4. **환경변수 이름만 합의**(값 절대 공유 금지): `KIS_MOCK_APPKEY`·`KIS_MOCK_APPSECRET`·
   `KIS_MOCK_CANO`·`KIS_MOCK_ACNT_PRDT_CD`(=`01`)·`KIS_ENV=mock`.
5. **읽기전용 프로브**(`scripts/kis_probe.py`, 토스 프로브의 KIS판) 로 토큰·잔고·미체결·체결내역
   조회만 검증(주문 없음).
6. 프로브 성공 → 어댑터(`bot/kis.py`) 구현 → 모의 Stage 1.5 → 실전 봇 계좌 Stage 2.

## 10. 리스크·미결 (Stage 2 전 실측)

`KIS_API_READINESS.md §12`와 동일. 최상위 3개:
1. **UNKNOWN 대사**(nccs+ccnl 휴리스틱으로 유실 주문 특정) — 안 되면 **Stage 2 No-Go**.
2. **파수꾼 마켓터블 지정가 손절**(연속장 시장가 부재) — 급락 방어 신뢰성.
3. **통합증거금 신용성격** — 현금 원칙 위배 여부.

→ 이 재계획을 Codex에 리뷰시킨다: `docs/kis/KIS_REVIEW_PROMPT.md`.
