🚀 3분 시작 가이드 — 뭐부터 보면 되나

이 도구가 하는 일 한 줄: 5,400여 종목(미국+한국)을 훑어서 "하락하다가 이제 막 상승으로 도는(전환) 종목을 저점에서" 골라주고, 진입가·손절가·목표가까지 계산해준다. 이미 오른 종목·잡주·폭등주는 자동으로 걸러진다.

매일 이 순서로 보면 끝 (3단계)

1
홈 열기 → 맨 위 "🤖 클로드라면 살 전환 후보"만 보기.
🔥 갓 전환 태그가 붙은 종목이 최우선(추세선을 방금 깨고 도는 중). ↗ 돌파후 진행은 참고만.
2
끌리는 종목 클릭 → 상세에서 딱 3가지 확인.
① 📋 매매 전략 카드의 진입·손절·목표 숫자 ② 📅 어닝 D-일(3일 이내면 패스) ③ 차트 모양이 정말 바닥 다지고 도는지 눈으로.
3
산다면 → 손절가를 미리 정해놓고 분할로. 그리고 holdings.json에 등록하면 손절/목표 도달 때 텔레그램 알림이 온다. 확신 없으면 💰 모의투자(가상 1,000만원)로 먼저 연습.

화면에서 이 4개만 알면 된다

📍 저점권 N%52주 최저~최고 사이 현재 위치. 낮을수록 저점(40% 이하 = 좋음).
🔥 갓 전환하락추세선을 방금 깨고 도는 중 — 이 도구가 노리는 바로 그 순간.
전환단계 ①~④①임박 → ②갓돌파 → ③돌파후 횡보 → ④확정. 클수록 확실, 작을수록 이름.
📊 추천 성과지난 추천이 실제로 맞았는지 자동 채점한 승률 — 도구를 믿을지 판단 근거.

메뉴 지도

홈추천 + 전체 종목 표(검색·필터·정렬)
💰 모의투자가상 1,000만원으로 추천을 실제처럼 연습
➕ 즉석조회목록에 없는 종목 티커 입력 → 1~2분 뒤 분석 추가
📘 매매 가이드왜 저점·전환을 노리는지, 체크리스트, 피해야 할 것

텔레그램 알림 받기 (선택 · 5분)

매수 후보가 새로 뜨거나, 기다리던 눌림에 도달하거나, 보유 종목이 손절/목표에 닿으면 알림.
1
텔레그램 @BotFather에게 /newbot → 토큰 받기
2
@userinfobot에게 아무 말 → 내 chat_id 확인
3
GitHub 저장소 → Settings → Secrets → Actions에 TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID 등록 — 끝.

철칙 하나

손절선을 깨면 판다 — 무조건. 이 도구의 적중률은 절반 안팎이고, 돈은 "맞을 때 크게, 틀릴 때 작게"(손익비)로 버는 구조다. 손절을 안 지키면 도구 전체가 의미 없어진다. 추천은 후보일 뿐, 최종 판단과 책임은 본인에게 있다.
